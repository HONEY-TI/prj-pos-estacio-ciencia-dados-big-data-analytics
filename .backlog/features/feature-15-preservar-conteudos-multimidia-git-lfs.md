## Contexto / Problema

Os vídeos dos módulos estavam sendo excluídos por regras de `.gitignore`,
impedindo que os materiais multimídia fossem publicados junto ao conteúdo didático.

## Objetivo

Versionar os arquivos `.mp4` com Git LFS, incluindo a configuração necessária nos
submódulos e no ambiente de desenvolvimento.

## Critérios de aceite

Rascunho: revisar e complementar manualmente antes da aprovação.
