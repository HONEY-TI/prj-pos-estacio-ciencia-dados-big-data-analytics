## Contexto / Problema

Rascunho: a configuração atual do ambiente Docker e do workspace precisa ser reorganizada
para acompanhar a estrutura de desenvolvimento utilizada pelo projeto.

## Objetivo

Rascunho: atualizar os arquivos de infraestrutura, inicialização, automação e configuração
do workspace sem perder a compatibilidade com os submódulos existentes.

## Critérios de aceite

Rascunho: revisar manualmente a inicialização do ambiente, a configuração do Dev Container,
os serviços Docker e a sincronização dos submódulos.
