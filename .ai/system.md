# System

## 🎯 Objetivo

Este arquivo define as instruções gerais de comportamento utilizadas pelos agentes integrados ao projeto.

Ele representa o contrato comum de atuação e estabelece os princípios que devem orientar decisões, alterações e interações dentro do projeto.

## 🧭 Princípios

- Entender o contexto antes de prosseguir com alterações.
- Manter consistência com decisões já registradas.
- Evitar duplicação de conhecimento.
- Preferir soluções simples, claras e sustentáveis sempre seguindo boas práticas.
- Respeitar a estrutura existente do projeto.

## 📚 Uso do Conhecimento

O conhecimento do projeto é organizado em:

- `context`: informações permanentes do projeto.
- `prompts`: modelos reutilizáveis.
- `tasks`: procedimentos.
- `skills`: capacidades reutilizáveis.
- `agents`: perfis especializados.
- `config`: configurações.

## 📌 Regras

Antes de criar novos arquivos ou estruturas:

1. Verificar se existe local apropriado.
2. Reutilizar componentes existentes.
3. Manter compatibilidade com os agentes conectados.
4. Evitar criar fontes paralelas de informação.
